# Contract: Operator Health, Startup, Shutdown, and Recovery

## Purpose

The operator must distinguish local application health, AI execution health,
and temporary public-route health on one Notebook. A generic "site is up" check
is insufficient. The detailed report is local-only; public health endpoints
return safe coarse status.

## Health scopes

| Scope | Meaning |
|---|---|
| Local application ready | Caddy, web, API, SQLite/storage, workflow manifest, ComfyUI, and GPU checks meet their local bounds |
| Generation admission ready | FastAPI can durably accept a validated job under queue/disk bounds and its real adapter configuration is valid |
| Engine reachable | ComfyUI responds within the dedicated health timeout; this does not promise generation success |
| Public test route ready | A current Quick Tunnel session reaches Caddy and the external page/API through HTTPS |

A stopped or interrupted Quick Tunnel makes only the public-route scope
unavailable. It does not make local generation unavailable and must not change
job data.

## Component matrix

| ID | Component | Independent local evidence | Ready result | Safe failure label |
|---|---|---|---|---|
| H1 | Network identity | Interface inventory | `161.200.90.4` is assigned when on the target lab network; no application listener owns it | `network_identity_unavailable` |
| H2 | Caddy | Listener plus `GET http://127.0.0.1:8080/` and API route probe | Loopback-only 8080; web and API routes split correctly | `reverse_proxy_unavailable` |
| H3 | Web experience | `GET http://127.0.0.1:3000/` | Usable page includes the temporary non-production notice | `web_unavailable` |
| H4 | FastAPI process | `GET http://127.0.0.1:8000/api/v1/health/live` | HTTP 200, body `{"status":"ok"}` | `api_unavailable` |
| H5 | Job admission | API readiness plus controlled mock admission test | DB/schema/adapter configuration and bounds allow safe admission | `job_service_unavailable` |
| H6 | Storage | Contained write/rename/remove probe, free-space reading, SQLite open/journal check | Writable, contained, supported SQLite mode, at least 10% free for new jobs | `storage_unavailable` or `low_storage` |
| H7 | Workflow | Manifest/schema/hash/binding/node/model/runtime verifier | Pinned workflow and dependencies match approved evidence | `workflow_unavailable` |
| H8 | ComfyUI | Bounded loopback `/system_stats` or adapter health call | Responds within five-second outer health bound | `engine_unavailable` |
| H9 | GPU execution path | `nvidia-smi` plus controlled workflow smoke/real run | RTX 5070 visible and the approved execution path completes | `gpu_unavailable` |
| H10 | Quick Tunnel process | Process/session state and connector-ready evidence | Outbound connector established for current session | `tunnel_unavailable` |
| H11 | Public HTTPS route | External `GET /`, `GET /api/v1/health/live`, and one controlled journey | Current disposable URL reaches the same Caddy boundary | `public_route_unavailable` |

H1 is deployment identity evidence, not a prerequisite when developing on a
different network. Release/public target-environment evidence must capture it.
No health check attempts direct application access through that address.

## Public health API

| Endpoint | Meaning | Body |
|---|---|---|
| `/api/v1/health/live` | FastAPI process can answer | `{"status":"ok"}` |
| `/api/v1/health/ready` | Job service, database/storage, and adapter configuration can safely admit according to current bounds | `{"status":"ok"}` or safe `503` with `unavailable`/`degraded` |
| `/api/v1/health/engine` | Current AI workflow service responds within its dedicated short health bound | `{"status":"ok"}` or safe `503` with `unavailable` |

These endpoints never include internal IPs/ports, process names, model or node
inventory, GPU details, paths, exception text, engine IDs, user content, tokens,
or the Quick Tunnel URL. H2, H3, H6-H11 remain operator-local checks.

## Local report contract

The operator health command produces machine-readable JSON and a concise human
summary with:

- UTC check time and overall scope results;
- one H1-H11 status (`ready`, `degraded`, `unavailable`, or `not_started`);
- safe reason code and elapsed time;
- a generated request ID when an HTTP probe is involved;
- non-zero exit code when a requested scope is not ready.

The report must not contain job tokens, raw URLs with their random Quick Tunnel
hostname, user filenames/content, generated bytes, private paths, ComfyUI prompt
IDs, stack traces, or raw service logs. A sanitized public-route value may be
recorded as `https://<temporary>.trycloudflare.com`.

## Startup contract

1. Confirm the target repository/configuration and verify no default
   `%USERPROFILE%\.cloudflared\config.yaml` or `config.yml` will interfere with
   Quick Tunnel. Do not rename/delete either file automatically.
2. Confirm application configuration contains no public bind, named-tunnel
   token, custom hostname, DNS operation, or second-host dependency.
3. Start `Local3D-ComfyUI` and wait within the documented 600-second cold-start
   bound for its loopback readiness.
4. Start the single `Local3D-API` process; complete SQLite/storage/workflow
   checks and restart reconciliation before admission reports ready.
5. Start `Local3D-Web` and verify the non-production notice.
6. Start/supervise Caddy on loopback 8080 and verify the exact route matrix,
   including a public-style Host header.
7. Run H2-H9. Do not expose the test endpoint while a mandatory local layer is
   unavailable.
8. Start one operator-controlled Quick Tunnel targeting
   `http://127.0.0.1:8080`. Use `info` or safer logging.
9. Extract the generated hostname for console display only, label it
   `TEMPORARY NON-PRODUCTION TEST URL`, and communicate it to the authorized
   test audience without committing it.
10. Run H10-H11 from the appropriate vantage point.

The local services may use WinSW automatic restart. The Quick Tunnel remains a
session process, not a named/token service, and may generate a new URL after any
restart.

## Shutdown contract

1. Stop advertising the temporary URL and terminate the Quick Tunnel process.
2. Stop Caddy so no new request reaches local upstreams.
3. Stop Next.js.
4. Ask FastAPI to stop admission and its background worker within a bounded
   grace period; close the ComfyUI adapter/client/thread and SQLite cleanly.
5. Stop ComfyUI after API shutdown completes or its grace period expires.
6. Verify cloudflared and loopback listeners are stopped as requested, while
   SQLite/job files remain present for restart reconciliation and retention.

A forced termination is allowed only as an explicitly recorded fallback. It
triggers the restart-recovery policy and must not be described as a clean stop.

## Restart recovery contract

After application or Notebook restart:

1. Complete startup reconciliation before `/health/ready` returns `ok`.
2. Rehydrate valid, never-submitted queued jobs in durable FIFO order.
3. Fail reserved/running jobs with `restart_recovery` unless exact tested engine
   reattachment proves ownership; never blindly resubmit.
4. Detect possible orphan ComfyUI prompts and interrupt/quarantine them without
   attaching output to a new/different job.
5. Revalidate completed assets before exposing result URLs. Record
   `output_missing` and suppress access to unavailable/corrupt content.
6. Remove only expired terminal files and safe orphan UUID directories covered
   by the retention/grace policy.
7. Restore accurate H2-H9 within five minutes of network readiness in each of
   three controlled Notebook trials.
8. Start a fresh Quick Tunnel, communicate its new temporary URL, and verify
   H10-H11. URL change requires no application migration.

## Failure diagnosis expectations

| Forced failure | Must remain available | Expected diagnosis within two minutes |
|---|---|---|
| Tunnel process stopped | Local web/API/AI/job data | H10/H11 unavailable; local scopes accurate |
| Caddy stopped | Direct local web/API/AI checks | H2 unavailable; H3-H9 independently accurate |
| Next.js stopped | API, accepted jobs, ComfyUI | H3 unavailable; API path through Caddy can remain diagnostic |
| FastAPI stopped | Web maintenance/unavailable guidance, ComfyUI | H4/H5 unavailable; no job is falsely completed |
| ComfyUI stopped/hung | Frontend, API liveness, durable job reads | H8 unavailable; new admission safe `503`; jobs reconcile/timeout safely |
| GPU unavailable/OOM | Web, API, stored jobs | H9 unavailable; active job safely fails; no partial result |
| Disk below 10% | Existing reads and accepted work where safe | H6 degraded/low storage; new jobs return `507` |
| Workflow/hash mismatch | Web and API liveness | H7 unavailable; real adapter fails closed, never switches to mock |
| Published GLB removed | Job history and authorization | H6 degraded; URLs suppressed; `output_missing`; no partial bytes |

## Exposure verification

Local authoritative evidence enumerates listeners and proves every application
port is bound only to `127.0.0.1`. External testing then probes
`161.200.90.4:3000`, `:8000`, `:8080`, and `:8188` only with explicit network
authorization. A successful TCP/application response is a failure. Refusal or
reset is corroborating evidence; timeout/drop alone is inconclusive and must be
paired with local listener and firewall/routing evidence.

The only permitted public success path is the current Quick Tunnel HTTPS URL.
No acceptance evidence may rely on WireGuard, Windows portproxy, direct inbound
443, a named Tunnel, or a custom DNS record.
